## How to play (for graders)

1. Open the **itch.io** build (or clone repo → Unity → `ChessPlaytest` → Play).  
2. Choose **Hot-seat** or **vs Computer**.  
3. Tap/click a piece, then a glowing square.  
4. Watch board flip / AI reply. Use **New Game** or **Modes** anytime.
